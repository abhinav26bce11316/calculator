# calculator # 🧮 Python Calculator with Graphical User Interface

A simple and user-friendly **Calculator Application** developed using **Python** and **Tkinter**.
The calculator provides a graphical interface with clickable buttons for performing basic mathematical calculations.

## 📌 Project Overview

This project is a beginner-friendly Python application designed to demonstrate the use of:

* Python programming
* Tkinter GUI
* Functions
* Conditional statements
* Event handling
* Button widgets
* User input and output

The calculator allows users to perform basic arithmetic operations through an easy-to-use graphical interface.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Modulus
* `( )` Parentheses
* 🔢 Decimal calculations
* 🧹 Clear button
* ⌫ Backspace button
* `=` Calculate button
* Graphical user interface
* Error handling for invalid calculations
* Protection against division by zero

## 🛠️ Technologies Used

| Technology | Purpose                             |

## 🚀 How to Run the Project

### Step 1: Install Python

Download and install Python from the official Python website.

During installation on Windows, make sure to check:

```text
☑ Add Python to PATH
```

### Step 2: Download the Project

Clone the repository using:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Or download the project as a ZIP file from GitHub.

### Step 3: Open the Project

Open the project folder in **VS Code**, **PyCharm**, or **IDLE**.

### Step 4: Run the Program

Open the terminal inside the project folder and run:

```bash
python calculator.py
```

The calculator window will open.

## 🖥️ How to Use

1. Click the number buttons to enter a number.
2. Select an arithmetic operator.
3. Enter the second number.
4. Click `=`.
5. The result will appear in the display.

### Example

```text
25 × 4

Result = 100
```

You can also use parentheses:

```text
(10 + 5) * 2

Result = 30
```
